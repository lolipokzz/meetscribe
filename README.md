# MeetScribe 0.9.0-beta.1

Локальная транскрибация встреч для Windows 10/11 x64: микрофон и системный звук,
история, русский/английский интерфейс и необязательное саммари.

Первая поставка — **portable beta** со встроенными Java, capture, CPU Whisper и
multilingual-моделью `small-q5_1`. Windows runtime ещё не проверен на целевых
устройствах: это не объявление стабильной версии 1.0. [Приёмка и доказательства](docs/release-acceptance.md).

## Быстрый старт

1. Распакуйте **весь** portable ZIP из `build/releases` и запустите `MeetScribe.cmd`.
   Отдельная установка Java и STT-модели не требуется. `start-debug.cmd --check`
   запускает техническую проверку со встроенной Java.
2. В настройках выберите микрофон и устройство системного звука из списка;
   `default` следует за устройством по умолчанию Windows. Проверьте папку сохранения.
3. Предупредите участников и начните запись. Доступны управление из трея,
   глобальная клавиша **Ctrl+Alt+R**, индикаторы и предупреждения о тихом источнике.
4. После остановки выполняется локальная транскрибация. В истории доступны просмотр,
   повторная обработка, возобновление, удаление аудио или встречи с подтверждением.

Запись использует общую временную шкалу. Хелпер автоматически переподключается
после смены default-устройства; отключённое явно выбранное устройство повторно
открывается до 30 секунд. Промежуток представляется тишиной. Этот код проверен
сборкой и portable-тестами, но аппаратные сценарии Windows ещё требуют приёмки.

## Саммари и приватность

После остановки записи и успешной STT саммари запускается автоматически, если
выбран соответствующий режим; для HTTP требуется согласие. Отдельная кнопка
позволяет повторить саммари из истории. По умолчанию оно отключено, `local-only` включён.

- `local`: встроен `llama-completion`, **веса LLM не включены**. Укажите собственную
  совместимую GGUF instruction-модель и размер контекста.
- `openai`, `anthropic`, `google` (Gemini), `openrouter`, `ollama`, `custom`:
  адаптеры через реестр провайдеров; `openai-compatible` сохранён для совместимости.
  Укажите модель, endpoint и ссылку на ключ. Поддерживается `провайдер/модель`.
- При сохранении/проверке настроек модель проверяется техническим запросом;
  для HTTP необходимо согласие. У локальной модели проверяются файл и оценка памяти.

Любой HTTP, включая Ollama на loopback, запрещён в local-only. Перед передачей
текста встречи требуется отдельное согласие; аудио не отправляется. Политика
`HKLM\SOFTWARE\Policies\MeetScribe\LocalOnly=1` не отменяется настройкой UI.
Ключи: `{env:OPENAI_API_KEY}` или `{credential:provider}` (Windows Credential Manager).
Открытый ключ в YAML запрещён. Само приложение не скачивает модели и не содержит
телеметрии или автообновлений. Live API и системные политики Windows ещё не приняты.

Язык саммари выбирается независимо от STT. Редактируемые шаблоны устанавливаются
в пользовательский профиль; кнопка «Открыть шаблоны» открывает каталог. Свой шаблон
UTF-8 до 64 KiB должен содержать `{{transcript}}`, опционально `{{language}}`.
Длинные встречи обрабатываются map/reduce. Можно настроить имя говорящего,
консервативное удаление дублей двух источников и удаление аудио после успешной
обработки: саммари, либо STT при режиме `none`. По умолчанию аудио сохраняется.

## Хранение и восстановление

Настройки: `%APPDATA%\MeetScribe\config.yaml`; на других ОС —
`~/.config/MeetScribe/config.yaml`. [Пример YAML](config/config.example.yaml).
Встречи: `yyyy-MM-dd_HH-mm-ss_UUID`, старые UUID-каталоги читаются.
Файлы: `meeting.json`, `mic.wav`, `system.wav`, `transcript.json`, `transcript.md`,
`transcript.commit`, необязательный `summary.md`. История показывает длительность.

Энергетический VAD выделяет диапазоны речи перед Whisper и возвращает timestamps
в исходную шкалу. Возобновление использует SHA-256 commit транскрипта; повреждённые
этапы выполняются заново. Канонический WAV после аварии восстанавливается по полным
кадрам на диске. Межпроцессные блокировки защищают обработку и активную запись.
STT завершается до загрузки LLM; отмена завершает native-процесс.

## Сборка из исходников

Нужен JDK 21. В IntelliJ IDEA откройте корень как Gradle-проект.

```powershell
.\gradlew.bat build
.\gradlew.bat :app:run
```

На macOS/Linux используйте `./gradlew`. Захват работает только на Windows;
для STT/LLM из исходников нужны соответствующие native CLI и модели в настройках.
Gradle при первой сборке загружает зависимости. Сборка portable ZIP и скрипт
MSI описаны в [packaging](packaging/README.md). **MSI здесь не собран и не испытан**.

Инженерная обработка двух выровненных WAV:

```sh
./gradlew :app:run --args='--transcribe /path/mic.wav /path/system.wav /path/results /path/whisper-cli /path/ggml-model.bin ru'
```

## Проверки и оставшиеся ограничения

Локально прошли **64 Java-теста** и два portable native-теста. Реальный Whisper
проверен на английской речи среди длинной тишины и на коротком русском TTS с
поставляемой `small-q5_1`. Это smoke-тесты, не подтверждение WER ≤15%.

Нужны Windows-приёмка записи/переподключения/трея/горячей клавиши, Credential Manager,
часовой drift, четырёхчасовой stress, чистая установка и live API. VAD энергетический,
не нейросетевой; диаризации нет. Качество саммари зависит от выбранных весов.
Поставка CPU; CUDA/Vulkan и автоматический выбор GPU не включены. Некоторые
технические диагностические сообщения остаются на английском. [Подробные проверки](docs/verification.md).

| Модуль | Назначение |
|---|---|
| `app` | JavaFX, настройки, tray/hotkey, Windows vault, capture IPC |
| `core` | VAD/PCM, этапы, хранение, recovery, история, map/reduce |
| `stt` | whisper.cpp process adapter |
| `llm` | Локальный llama.cpp и реестр HTTP-провайдеров |
| `capture-windows` | WASAPI C++20, reconnect, PCM/WAV, JSONL |
| `packaging` | Portable ZIP и Windows jpackage/MSI script |
