# Приёмка первой версии: доказательства и ограничения

Дата проверки: 5 октября 2026. Статусы ниже различают написанный код,
автоматическую проверку и приёмку на целевом Windows-компьютере. Наличие функции
в коде не означает выполнение всех требований к качеству и надёжности.

## Проверено в обработке аудио и хранении

| Требование | Реализация и свидетельство | Статус |
|---|---|---|
| Локальная STT двух источников | Whisper CLI; последовательная обработка; нормализация 16 kHz PCM16; освобождение STT до загрузки LLM | Код и native smoke проверены на macOS CPU |
| Пропуск тишины с исходными timestamps | VAD по кадрам 20 мс, порог по шумовому фону, hysteresis, padding; чанки ≤60 с | Синтетические тесты и реальный Whisper проверены |
| История и длительность | `yyyy-MM-dd_HH-mm-ss_UUID`, совместимость с UUID, `durationSeconds` | Автоматические тесты |
| Восстановление записи | Исправление размеров RIFF/data канонического capture WAV по фактическим полным кадрам | Тест повреждённого заголовка; реальный kill на Windows ещё нужен |
| Возобновление STT | SHA-256 commit двух файлов транскрипта; `resume` повторно использует только целый commit | Автоматический тест, включая повреждённый транскрипт |
| Защита от конкурирующих операций | OS file lock; запись держит его до остановки/ошибки | Тест двух экземпляров сервиса; Windows multi-process ещё нужен |
| Имя говорящего и дедупликация | Настраиваемое имя; опциональное удаление равных реплик разных источников в пределах 1 с | Тест всего pipeline через CLI fixture |
| Язык и шаблон саммари | Независимый язык; UTF-8 шаблон ≤64 KiB, `{{transcript}}` и `{{language}}`; bounded map/reduce | Автоматические тесты |
| Сохранность аудио | По умолчанию сохраняется; опциональное удаление после успешного саммари | Автоматические тесты ошибок, отмены, удаления |

Core regression suite содержит 22 теста; `:core:test` и `:stt:test` прошли.
Это число относится к проверке данного изменения, а не ко всему проекту.

## Реальная проверка VAD → Whisper

Применялся настоящий whisper.cpp v1.7.6 (commit
`a8d002cfd879315632a579e73f0148d06959de36`), CPU build на macOS arm64.
Подмена CLI или ответы-заглушки в этих двух smoke-сценариях не использовались.

### Английская речь, длинная тишина и смещения

В 120-секундный PCM WAV вставлены две копии 11-секундного `samples/jfk.wav`
из whisper.cpp: на отметках 30 и 80 секунд. Второй источник — 120 секунд тишины.
Модель `ggml-tiny.en.bin`, SHA-256:
`921e4cf8686fdd993dcd081a5da5b6c365bfde1162e72b08d75ac75289920b1f`.

Результат: **PASS**. VAD нашёл диапазоны 29,76–41,40 и 79,76–91,40 секунд;
Whisper вернул узнаваемую полную реплику в обоих местах с timestamps
29,76–40,76 и 79,76–90,76. Сохранённая длительность встречи — 120 секунд.
Тихий источник не отправлялся в STT. Harness проверяет наличие обеих областей,
содержание, пределы времени и длительность. Wall time всего вызова на этой машине
составил 0,86 секунды; это разовый smoke, не результат квалификационного benchmark.

Локальные проверочные материалы: `/private/tmp/meetscribe-release-validation/`:
`NativeVadSmoke.java`, `offset-jfk.wav`, `native-vad-en-report.json`.
Они не входят в релиз и могут быть удалены системой как временные файлы.

### Русская речь

Результат: **PASS**. Использован уже установленный голос macOS Milena ru_RU;
никаких голосов не устанавливалось. Локально синтезированы пять предложений
длительностью 13,45 секунды; второй канал — 120 секунд тишины. Выбранная для
поставки модель `ggml-small-q5_1.bin` (190 085 487 байт), SHA-256:
`ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb`.

Все пять предложений распознаны: «Сегодня мы обсуждаем первую версию приложения»,
«Анна подготовит документацию к пятнице», «Борис проверит запись звука на
компьютере», «Решили хранить все записи локально», «Следующая встреча состоится
в понедельник». Программное сравнение слов без пунктуации и регистра дало точное
совпадение с коротким TTS-эталоном. Получены пять сегментов от 0 до 13,40 секунды;
wall time всего вызова — 3,37 секунды. Это разовый smoke, не benchmark.

Отчёт: `/private/tmp/meetscribe-release-validation/native-vad-ru-report.json`.
Это **не квалификация WER**: синтетический голос не воспроизводит шум, акценты,
разговорную речь и перекрытие голосов реальных встреч. Даже точное совпадение
на этом образце не доказывает требование WER ≤15% на рабочем корпусе.

## Ограничения, которые не скрываются за статусом «код готов»

- VAD энергетический, не нейросетевой: музыку/шум он может принять за активность,
  а очень тихую речь — пропустить. Непрерывная речь может попасть на границу чанка.
- Обозначения источников не являются диаризацией людей. Дедупликация не семантическая.
- Содержание и структура саммари зависят от модели. Автотест не доказывает
  отсутствие галлюцинаций, полноту задач и решений или качество русского текста.
- Summary и metadata сохраняются отдельными атомарными операциями; после аварии
  между ними provenance может быть устаревшим. Transcript commit защищён отдельно.
- Исправление WAV не восстанавливает аудио, которое capture/ОС не успели записать.
- Native smoke на macOS не проверяет WASAPI, Credential Manager, MSI или GPU Windows.

## Обязательная ручная приёмка перед объявлением стабильного Windows-релиза

| Проверка | Критерий / нужное свидетельство | Статус |
|---|---|---|
| Windows 10/11 и устройства | Минимум пять конфигураций; mic + loopback; выбор и смена устройства; отключение/подключение | Ожидает Windows hardware |
| Zoom, Meet, Teams | Часовая встреча в каждом, рассинхронизация ≤0,5 с | Не проверено |
| Длительная запись | До 4 часов, недостаток диска, kill процесса, сохранённые файлы/диагностика | Не проверено на Windows |
| Русская STT | Репрезентативный размеченный корпус, WER ≤15%, latency, CPU/RAM | Не квалифицировано |
| Саммари длинных встреч | Двухчасовая запись, задачи/владельцы/сроки, контролируемая фактическая полнота | Не квалифицировано |
| Провайдеры | Запросы с реальными пользовательскими ключами, ошибки API, таймауты, лимиты | Нужны live API credentials |
| Локальный режим | Проверка системного запрета cloud и сетевого трафика процесса | Нужен Windows network audit |
| Установщик | Установка/запуск/удаление на чистой Windows, запуск без отдельно установленной Java | Ожидает целевую ОС |
| GPU и fallback | Проверка реально поставляемых backend на совместимых устройствах; CPU fallback | Ожидает целевые GPU |
