# Решения 0.9.0-beta.1

| Решение | Причина / предел |
|---|---|
| Java 21, JavaFX, отдельный C++ WASAPI | Базовый стек и изоляция записи |
| Whisper/llama CLI вместо JNI, прямые HTTP adapter вместо LangChain4j | Явный lifecycle, освобождение памяти и меньше ABI-зависимостей |
| Portable ZIP со своей Java и CPU small-q5_1 | Первый запуск STT без ручной установки Java/весов; Windows runtime ещё не принят |
| Встроен llama-completion без GGUF | Выбор качества/размера/лицензии LLM остаётся пользователю |
| Summary none и local-only true по умолчанию | Транскрипт работает без LLM; HTTP запрещён, включая Ollama loopback |
| ProviderRegistry + native Anthropic/Gemini протоколы | Единые политики, проверка модели и формат provider/model; live API требуют приёмки |
| Date_UUID и OS file lock | Читаемая дата, отсутствие коллизий, защита нескольких экземпляров |
| Энергетический VAD с padding + area-average PCM | Небольшие зависимости и сохранение исходной шкалы; не замена neural VAD/quality benchmark |
| SHA-256 commit для transcript/resume | Повреждённый незавершённый этап не считается готовым |
| Саммари после записи и отдельная повторная кнопка; редактируемый шаблон | Повторное саммари без STT и явное согласие на передачу текста |
| CPU beta; MSI только build script | GPU/чистая Windows-приёмка/подпись требуют отдельной среды |

Лицензию собственного кода (например, MIT или Apache-2.0) выбирает автор: она здесь
не назначена. До публичного релиза нужны проверка имени, учёт лицензий всех весов
и компонентов, решение о подписи и завершение целевой приёмки. Версия beta не
переопределяет требования ТЗ 1.0.
